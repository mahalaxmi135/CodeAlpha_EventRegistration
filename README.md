# CodeAlpha Event Registration System

A Django-based web application for managing events and user registrations.

## Features

- View available events
- View event details
- Register for an event
- View all registrations
- Cancel a registration
- Manage events through Django Admin
- Store event and registration data using SQLite

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
